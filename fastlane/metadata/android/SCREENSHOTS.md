# Store graphics

- `en-US/images/icon.png`: existing Sele artwork, 512×512 PNG.
- `en-US/images/featureGraphic.png`: 1024×500 opaque PNG using existing artwork.
- `en-US/images/phoneScreenshots`: four genuine Android app captures at 1080×1920.

Screenshots use an isolated emulator and a local test host with representative
sample content. No real user conversations, credentials, or provider accounts
appear. The renderer and Android UI are the same as the release candidate; the
sample host supplies conversation, model and project data. Screenshots were
captured through the debug variant to automate sample setup. The separately signed
release variant was also installed and checked for startup and disabled debugging.

Suggested screenshot accessibility descriptions:

1. Continue an AI coding conversation from your phone.
2. Browse conversations grouped by workspace.
3. View project files in the mobile workspace.
4. Start a conversation using a provider configured on your computer.

Review and refresh these assets if the interface or privacy/reporting flows change
before submission. They are prepared assets, not an uploaded Play listing.
